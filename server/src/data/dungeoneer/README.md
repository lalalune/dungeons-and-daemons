# Data from Dungeoneer

The JSON files in this folder are copied unmodified from
[Dungeoneer](https://github.com/Durtur/Dungeoneer) by Durtur, commit
`dca8a177bcf237e95a3eb8e6a080b7d0e07fdf98`, `data/` folder.

Dungeoneer is licensed under the GNU Affero General Public License v3.0.
Because this project includes these files, the project as a whole is
distributed under the same licence (see `LICENSE` at the repository root).

- `items.json`: magic items (used for loot)
- `spells.json`: spell descriptions (shown on the character sheet)
- `conditions.json`: what each condition does
- `names.json`: name lists (given to the Dungeon Master for new characters)
