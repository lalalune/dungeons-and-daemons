# Maps from Dungeoneer

These maps (images, wall lines and animation settings) are converted from the
default map library of [Dungeoneer](https://github.com/Durtur/Dungeoneer) by Durtur,
commit `dca8a177bcf237e95a3eb8e6a080b7d0e07fdf98`, `data/default_library/`, licensed AGPL-3.0.
Images were resized and re-encoded; wall coordinates were normalized to 0..1.
